# 💰 Personal Finance Manager

A comprehensive personal finance manager built with C and ncurses.

## ✨ Features

- ✅ Add income and expenses
- ✅ Categories for transactions
- ✅ Auto-capture date/time
- ✅ Budget management with alerts
- ✅ Monthly and yearly reports
- ✅ Income vs expense tracking
- ✅ Savings calculation
- ✅ Filter by month/category
- ✅ Save/Load data
- ✅ ncurses GUI with colors

## 🛠️ Planned Features

- [ ] ASCII charts for reports
- [ ] Export to CSV
- [ ] Search transactions
- [ ] Edit/Delete transactions
- [ ] Multiple accounts

## 🚀 How to Compile

```bash
gcc -Wall -Wextra -o finance_manager main.c -lncurses
```
## 🏃 How to Run
```bash
./finance_manager
```

## 📁 Data Files

    transactions.txt - All transactions

    budgets.txt - Budget limits per category
